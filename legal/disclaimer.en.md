## Game materials

- The website and the program **do not contain or distribute** images, sounds, videos, fonts or other files of the game.
- The website does not show pictures from the game. A user may pick the file of their own installed game: the pictures are then read from it in the browser, on the user's device, and are not sent anywhere. The desktop version reads them the same way from the game installed on the user's computer.
- The editor's reference data contains identifiers, numeric properties, names and descriptions of game objects. They are used only to identify objects in the editor.

## Saves

The editor works only with files the user picked on their own device. It does not interfere with the game, its servers or online features and does not affect other players. The user is responsible for editing their saves and for following the terms of the game.
