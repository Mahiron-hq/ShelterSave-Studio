# ShelterSave-Studio – Fallout Shelter save editor

ShelterSave-Studio is a free open-source editor for Fallout Shelter save files (`Vault1.sav`, `Vault2.sav`, `Vault3.sav`). It works right in the browser: the file is decrypted and edited on your device and is never uploaded.

## What you can edit

- Resources, lunchboxes, Mr. Handy and pet carriers, storage items, recipes and themes.
- The vault map: build, move, merge, split and upgrade rooms, clear rocks.
- Dwellers: level, S.P.E.C.I.A.L., health, happiness, looks, outfits, weapons, pets, relations, children.
- Quests, daily and weekly objectives, achievements, wasteland teams and their loot, incidents and event timers.
- Every key of the file in expert mode.

## Why the game keeps loading your save

- The rules come from the game's own data and code (Fallout Shelter 2.7): allowed values, room sizes and levels, health formulas.
- Linked data changes together, the way the game does it.
- An integrity check with 25 rules from the game code finds problems that make the game crash or hang, and fixes most of them with one button.
- The file changes only where you changed it, and every edit can be undone.

The same editor is available as a [desktop program for Windows, Linux and macOS](/en/desktop/). How to find the save and put it back: [help](/en/help/). Source code: [GitHub](https://github.com/Mahiron-hq/ShelterSave-Studio).
