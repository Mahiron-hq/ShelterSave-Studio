# Безопасность / Security

[Русский](#русский) · [English](#english)

## Русский

### Как сообщить об уязвимости

Напишите на Mahiron.HQ@protonmail.com с темой «ShelterSave-Studio security». Не публикуйте уязвимость в открытых задачах GitHub, пока она не исправлена.

Укажите, если можете:

- версию программы или адрес страницы сайта;
- что именно не так и чем это опасно;
- шаги, чтобы повторить проблему;
- файл или запрос, на котором она видна (без чужих личных данных).

### Сроки

- Ответ с подтверждением получения – в течение 3 дней.
- Первая оценка и план – в течение 7 дней.
- Исправление серьёзной уязвимости – как можно скорее, обычно в течение 30 дней. О сроках я сообщу в переписке.

Когда исправление выйдет, я по вашему желанию укажу вас в описании выпуска.

### Что входит

- ПК-версия ShelterSave-Studio и её установщик.
- Сайт shelter.mahiron.online и сервер `shelter-site` (раздача сайта, статистика, сторож и бот).
- Код этого репозитория.

Не входят: сама игра Fallout Shelter, сервисы Bethesda и Valve, атаки на доступность (DoS) и социальная инженерия.

### Поддерживаемые версии

Исправления выходят для последней версии.

## English

### How to report a vulnerability

Email Mahiron.HQ@protonmail.com with the subject "ShelterSave-Studio security". Please do not post the vulnerability in public GitHub issues until it is fixed.

If you can, include:

- the program version or the website page address;
- what is wrong and why it is dangerous;
- steps to reproduce it;
- a file or request that shows it (without other people's personal data).

### Response times

- Acknowledgement within 3 days.
- First assessment and plan within 7 days.
- A fix for a serious vulnerability as soon as possible, usually within 30 days. I will tell you the timeline by email.

When the fix is released, I can credit you in the release notes if you wish.

### Scope

- The ShelterSave-Studio desktop program and its installer.
- The website shelter.mahiron.online and the `shelter-site` server (site, statistics, watchdog and bot).
- The code in this repository.

Out of scope: the Fallout Shelter game itself, Bethesda and Valve services, denial-of-service attacks and social engineering.

### Supported versions

Fixes are released for the latest version.
